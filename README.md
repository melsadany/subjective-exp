# Bipolar Disorder Analysis from Reddit Data

Natural Language Processing pipeline for identifying individuals with bipolar disorder from Reddit and analyzing their posting patterns, sentiment changes, and behavioral markers.

## Overview

This project extracts Reddit data to identify users with bipolar disorder, collects their complete posting history, and performs comprehensive NLP analysis including sentiment dynamics, sleep patterns, activity fluctuations, and linguistic markers.

## Features

- **User Identification**: Detect self-reported bipolar users through keyword filtering and pattern recognition
- **Data Collection**: Extract complete user posting history and metadata
- **Temporal Analysis**: Track activity patterns, posting frequency, and time-of-day patterns
- **Sentiment Analysis**: Measure emotional volatility and mood swings
- **Sleep Pattern Detection**: Identify sleep-related mentions and circadian rhythm disruptions
- **Linguistic Analysis**: Extract psycholinguistic markers and topic modeling

## Ethical Considerations

**Anonymization**: All usernames and identifying information removed
**Data Privacy**: Analysis conducted on public posts only
**Research Compliance**: Follows Reddit API terms of service
